Phase Lab

Where does this stop working? Each cell hides a random k-sparse vector of length N = 256, measures it M times, and asks whether ℓ1 minimisation gives it back exactly. The x-axis is how much of the signal is non-zero (ρ = k/N). The y-axis is the budget (δ = M/N). The white line is ψ(ρ), the statistical dimension of the ℓ1 descent cone. It comes from a one-line integral and is drawn before the first trial runs.

cells—workers
trials—basis-pursuit solves
agreement—cells on the predicted side of ψ

Hover a cell for its numbers.

A failure is certified rather than waited for. The solver's iterate always satisfies Ax = y, so the moment its ℓ1 norm drops below the hidden vector's, that vector cannot be the minimiser. Most failed trials end within a few dozen steps.

The bench

Each row takes its expected value from somewhere the solvers never see: a closed-form integral, a published theorem, a dense matrix, or the PRD's own target. The row shows what was expected, what came out, and whether it passed. Rows run in parallel across workers, and the same file runs under Node with node tests.mjs.

—

    Walsh–Hadamard sensing with fast transforms, total variation by Chambolle–Pock, ℓ1 wavelet recovery by FISTA with continuation, basis pursuit by over-relaxed ADMM with certified early failure. No libraries, no build step. The same modules run in the page, in the workers and under Node.
