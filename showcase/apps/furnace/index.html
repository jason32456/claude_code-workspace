Furnace

A Monte Carlo path tracer, and a test it cannot fake. Put a pure white sphere inside a void that glows pure white, and the sphere has to disappear — every photon that lands on it leaves again, so it can be neither brighter nor darker than what is behind it. If you can still see it, the renderer is losing energy. Most cannot pass this.

Where rough metal loses its light

The same furnace, with a GGX microfacet metal of albedo 1 instead of a diffuse sphere. Single scattering cannot pass: the Smith masking term removes the light a microfacet blocks and never puts it back, so a surface that should return everything returns two thirds less of it. This is not a bug in the implementation — it is what single-scatter GGX is, and it is why the compensation term exists.

The bench

A path tracer is the easiest kind of program to be wrong about, because wrong renders look fine. Each check is decided by something that is not an opinion about an image: a closed-form answer, a convergence rate that follows from the central limit theorem, or an identity two configurations must satisfy whatever the picture looks like.

Spheres and a plane, intersected analytically. Lambertian, conductor, dielectric and GGX microfacet surfaces; cosine-weighted hemisphere sampling; Russian roulette; ACES tone mapping. No acceleration structure, because the scenes are small enough that a BVH would be more code than it saved. The tracer runs unchanged in the page, in the workers that draw it, and under Node for the bench.
